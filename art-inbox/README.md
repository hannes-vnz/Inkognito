# Eingang für Grafiken

Hier Rohbilder hochladen (PNG oder JPG, gern zu groß, Hintergrund egal).
Claude spielt sie mit `npm run art:import` ein und räumt den Ordner danach wieder leer.

Am besten im Dateinamen sagen, was es ist, z. B. `bert_talk_1.png`, `bert_talk_2.png`, `portrait_hilde_happy.png`, `fish_kabeljau.png`.
Mehrere Bilder einer Animation in der richtigen Reihenfolge nummerieren.
